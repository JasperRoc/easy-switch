# Skills & MCP

**Your tools, in the clients you use.**

Open **Settings → Skills** or **Settings → MCP**. Each item has independent Codex and Claude Code switches.

| Skills | MCP |
| --- | --- |
| Import a folder, Git repository or supported source. Enable it for the chosen client. | Add a local command or HTTP server, then enable it for the chosen client. |
| Use **Update all** for managed Git sources. | Keep secrets in the server’s environment, not shared screenshots. |
| Local unmanaged folders are left intact when removed from fluid. | Confirm required runtimes and server permissions are available. |

Reload the client after editing. Skills appear according to that client’s discovery rules; MCP tools do not automatically become `/` commands. Server-provided prompts can appear where the client supports them.
