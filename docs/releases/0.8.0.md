## fluid, simplified

- Use `fd <alias>` for Codex and `fd cc <alias>` for Claude. Add accounts/APIs, edit, remove, list and reorder with the compact command set. Update, uninstall and help are the only global management commands.
- Rebuild the English and Chinese README around actual screenshots, quick setup and concise feature guides.
- Unify source, package identities, configuration paths and executables under fluid. The app data directory is `~/.fluid`; the local Codex provider is `fluid`.
- Move tests and build scripts to TypeScript. Keep generated JavaScript outside the source tree.
- Run the release workflow only for version tags or manual builds, eliminating duplicate main-branch builds. Keep platform, signing and installer verification.

**Clean installation:** quit the previous application normally so it restores client settings. Keep an independent backup before removing an older installation. This release uses new application/data identities and does not automatically import a different identity’s account store. Existing remote encrypted data retains its protocol key derivation; join an existing library using its full saved URL.

macOS previews remain ad hoc signed until Developer ID and notarization credentials are configured. Free-account images require actual official image access/quota and the installed browser fallback; no subscription permission is bypassed.

## 更简洁的 fluid

- Codex 使用 `fd <alias>`，Claude 使用 `fd cc <alias>`；通过精简命令添加账号／API、编辑、删除、查看和调整顺序，全局管理仅保留更新、卸载和帮助。
- 重写中英文 README，使用真实界面的演示截图、快速开始和简明功能指南。
- 源码、安装包身份、配置路径和可执行文件统一为 fluid。数据目录改为 `~/.fluid`，Codex 本地服务商标识为 `fluid`。
- 测试和构建脚本迁为 TypeScript，生成的 JavaScript 不进入源码仓库。
- 发布工作流仅在版本标签或手动构建时运行，停止 main 推送时的重复构建，保留跨平台、签名和安装器检查。

**重新安装：**先正常退出旧程序，让它恢复客户端设置。移除旧安装前请另存备份。此版本使用新的应用和数据身份，不自动导入其他身份的账号存储。已有远端加密数据继续使用原协议密钥派生，加入已有存储时填写其完整地址。

未配置 Developer ID 和 Apple 公证前，macOS 安装包仍为临时签名预览版。Free 图片适配依赖账号的真实官方图片权限／额度及本机浏览器，不绕过订阅权限。
