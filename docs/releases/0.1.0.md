## fluid v0.1.0

- Switch Codex and Claude accounts or APIs through one local route, with ordered fallback providers.
- Continue selected sessions across computers using encrypted SSH or WebDAV storage, including Git state and uncommitted changes.
- View requests, tokens, cache usage and estimated costs by provider and model.
- Generate images inside Codex using saved ChatGPT accounts, including Free accounts when their official image access and quota permit.
- Manage Skills and MCP for Codex and Claude Code.
- Use the desktop tray on macOS and Windows, or the compact `fd` CLI on Linux.

Download the package for your platform below. SHA-256 checksums are included. macOS packages are ad hoc signed previews; first launch requires system approval.

This release starts fluid’s version numbering at v0.1.0. If a higher preview version is already installed, quit it normally, back up your configuration and install this version manually.

## fluid v0.1.0

- 通过统一的本地路由切换 Codex、Claude 账号与 API，按优先级尝试备用服务商。
- 使用 SSH 或 WebDAV 加密同步选定会话、Git 状态及未提交改动，换台电脑继续工作。
- 按服务商和模型查看请求、Token、缓存用量及参考费用。
- 在 Codex 中使用已保存的 ChatGPT 账号生成图片；Free 账号须具有官方图片权限及可用额度。
- 集中管理 Codex 和 Claude Code 的 Skills、MCP。
- macOS、Windows 使用桌面托盘，Linux 使用精简的 `fd` 命令。

请在下方下载对应平台的安装包，附带 SHA-256 校验值。macOS 安装包为临时签名预览版，首次打开需要系统授权。

fluid 从 v0.1.0 开始编号。如果已安装版本号更高的预览版，请先正常退出并备份配置，再手动安装本版。
