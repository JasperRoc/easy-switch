# Third-party components

Desktop distributions include Electron (MIT), Node.js and Chromium (their bundled notices), and the official OpenAI Codex CLI **0.165.0** (Apache-2.0). Codex is used for official device sign-in and local model-catalog discovery. The helper also supplies model display/effort metadata for exact IDs already returned by a provider; it never supplies fallback availability. Its source is available at <https://github.com/openai/codex/tree/rust-v0.165.0>; its license is included as [CODEX-LICENSE](CODEX-LICENSE) and alongside the bundled executable.

The bundled Codex executable comes from the matching, pinned `@openai/codex` npm platform package. macOS distribution signing may update its signature without changing its program code. Audio and code-execution helpers are not bundled because the desktop application does not use those features. Desktop users still use their own Codex client for conversations.

Runtime dependencies include `smol-toml` (MIT) and `undici` (MIT). Their license files and Electron's component notices are included with the packaged dependencies. Build-time dependencies are listed in `package.json` and `package-lock.json`.

Claude subscription login invokes the user's separately installed official Claude Code CLI. Claude Code is proprietary software governed by Anthropic's terms and is not included in easy-switch's MIT distribution. The tool reads only the selected official credential store and uses isolated sign-ins when adding accounts; credentials are not redistributed.

The Claude Desktop adapter was informed by [CC Switch's Desktop integration](https://github.com/farion1231/cc-switch/blob/5a3d7f92ab696b9d35c08ac9bc81e4067de6f9bc/src-tauri/src/claude_desktop_config.rs) (MIT, Copyright (c) 2025 Jason Young) and the installed Desktop configuration schema. easy-switch implements its own JavaScript adapter and shared route. Its independent Fable / Opus / Sonnet / Haiku mapping was also informed by [CC Switch’s model mapper](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/proxy/model_mapper.rs). The sidebar layout and Codex plan-label handling were also informed by [CC Switch’s sidebar](https://github.com/farion1231/cc-switch/blob/main/src/components/shell/Sidebar.tsx) and [subscription service](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/services/subscription.rs). easy-switch keeps its own DOM UI and account/routing implementation. The upstream MIT notice is retained in [CC-SWITCH-LICENSE](CC-SWITCH-LICENSE).

The model catalog editor was informed by [DeepSeek Harness’s model list editor](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/client/ui-settings-models) (MIT, Copyright (c) 2026 DeepSeek): separate upstream IDs and display names, draft/save behavior and model ordering. easy-switch uses its own JavaScript DOM implementation; the upstream notice is retained in [DEEPSEEK-HARNESS-LICENSE](DEEPSEEK-HARNESS-LICENSE).
