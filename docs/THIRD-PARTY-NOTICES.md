# Third-party components

Desktop distributions use Tauri (MIT or Apache-2.0), the system WebView, and a bundled Node.js runtime. The [Node.js license and bundled component notices](NODE-LICENSE) are included in desktop packages. The optional account-image fallback launches an installed Chrome or Edge process with a temporary profile.

Codex device sign-in and account refresh use the installed official Codex executable. The sanitized catalog in `src/codex-model-metadata.json` supplements display, effort, and context-window metadata for exact IDs returned by a provider. It is based on [OpenAI Codex](https://github.com/openai/codex) and its [Apache-2.0 license](CODEX-LICENSE).

Worker dependencies include `smol-toml`, `undici`, and the ZIP reader `yauzl`. Their licenses are included with the packaged dependencies. Rust and TypeScript dependencies are listed in their lockfiles.

Claude subscription login invokes the user's separately installed official Claude Code CLI. Claude Code is proprietary software governed by Anthropic's terms and is not included in fluid's MIT distribution. The tool reads only the selected official credential store and uses isolated sign-ins when adding accounts; credentials are not redistributed.

The Claude Desktop adapter was informed by [CC Switch's Desktop integration](https://github.com/farion1231/cc-switch/blob/5a3d7f92ab696b9d35c08ac9bc81e4067de6f9bc/src-tauri/src/claude_desktop_config.rs) (MIT, Copyright (c) 2025 Jason Young) and the installed Desktop configuration schema. fluid implements its own TypeScript adapter and shared route. Its independent Fable / Opus / Sonnet / Haiku mapping was also informed by [CC Switch’s model mapper](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/proxy/model_mapper.rs). The sidebar layout and Codex plan-label handling were also informed by [CC Switch’s sidebar](https://github.com/farion1231/cc-switch/blob/main/src/components/shell/Sidebar.tsx) and [subscription service](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/services/subscription.rs). fluid keeps its own DOM UI and account/routing implementation. The upstream MIT notice is retained in [CC-SWITCH-LICENSE](CC-SWITCH-LICENSE).

The model catalog editor was informed by [DeepSeek Harness’s model list editor](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/client/ui-settings-models) (MIT, Copyright (c) 2026 DeepSeek): separate upstream IDs and display names, draft/save behavior and model ordering. fluid uses its own TypeScript DOM implementation; the upstream notice is retained in [DEEPSEEK-HARNESS-LICENSE](DEEPSEEK-HARNESS-LICENSE).

The per-client Skills and MCP controls were informed by [CC Switch's MCP guide](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/3-extensions/3.1-mcp.md) and [Skills guide](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/3-extensions/3.3-skills.md).

The transparent ChatGPT and Claude client marks are extracted from the user-supplied official product icon references and remain the property of their respective owners. OpenAI, ChatGPT, Codex, Anthropic, Claude, Windows and macOS are trademarks of their respective owners. This independent project does not imply sponsorship or endorsement.

Usage counters and provider/model breakdowns were informed by [CC Switch’s usage dashboard](https://github.com/farion1231/cc-switch/blob/main/src/components/usage/UsageDashboard.tsx), [response parser](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/proxy/usage/parser.rs) and [cost calculator](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/proxy/usage/calculator.rs). fluid uses its own bounded Rust stream observer, local metadata journal and DOM UI, with provider-specific pricing. The upstream MIT notice is retained in [CC-SWITCH-LICENSE](CC-SWITCH-LICENSE).

The request-log columns, configurable visibility, local-session usage source and image endpoint aliases were also informed by CC Switch commit [d2bb4c8](https://github.com/farion1231/cc-switch/tree/d2bb4c8d434b25f5aa14911dda0c9e51ed8021ed), in particular `RequestLogTable.tsx`, `requestLogColumns.ts`, `services/session_usage_codex.rs` and `proxy/handlers.rs`. fluid implements the behavior within its existing DOM interface, bounded TypeScript log reader and Rust gateway; it does not bundle CC Switch’s React application or database.
