# Skills 与 MCP

**把熟悉的工具带到正在使用的客户端。**

打开 **设置 → Skills** 或 **设置 → MCP**。每个条目可以分别对 Codex、Claude Code 开启。

| Skills | MCP |
| --- | --- |
| 导入本地文件夹、Git 仓库或支持的来源，为目标客户端启用。 | 添加本地命令或 HTTP 服务，为目标客户端启用。 |
| 托管的 Git 来源可「一键更新」。 | 密钥放在服务环境里，不放进共享截图。 |
| 移除配置不会删除未托管的用户文件夹。 | 确认运行环境、服务权限可用。 |

修改后重新加载客户端。Skills 按客户端自己的规则发现；MCP 工具不会自动变成 `/` 命令，只有客户端支持的服务端提示词才会出现在相应菜单。
